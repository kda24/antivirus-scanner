# Antivirus Scanner

A Python-based cybersecurity project designed to detect potentially malicious files using signature-based scanning techniques. The project demonstrates fundamental antivirus concepts such as file analysis, malware signature detection, directory scanning, and threat reporting.

## Features
- Scan individual files and folders
- Signature-based malware detection
- Real-time scan alerts
- Detailed scan reports
- Simple command-line interface

## Technologies Used
- Python
- OS Module
- Hashlib
- File Handling
- Cybersecurity Concepts
